# LectureBrief repository instructions

- Use `pnpm` for workspace commands.
- Treat `ARCHITECTURE.md` as the product contract and `BUILD_PLAN.md` as the execution checklist.
- Preserve stable item IDs across extraction and publication so existing comments remain attached.
- Never publish draft lectures, redacted items, or untested prompts.
- Keep generated caches and deployment output out of Git.
- Follow nested `AGENTS.md` files for package-specific rules.
